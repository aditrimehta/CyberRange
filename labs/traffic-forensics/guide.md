# Security Log Analysis

This lab searches a small, synthetic access log bundled with the project. The IP addresses are reserved documentation examples, and the usernames and filenames are fictional.

## Tasks

1. Search for `failed` and note the source address and timestamps.
2. Search for `192.0.2.44` to see the sequence of attempts and the later block event.
3. Search for `file_upload` and record the uploaded filename.
4. Use the evidence to answer the questions and build a short incident timeline.
5. Submit for a score and explanations.

The search is performed against the bundled log file. It does not access your computer's logs or a network service.
